# Forami Logo 候选

使用内置 `image_gen` 生成的五个独立设计方向。用户已通过附图明确选定第三个「负形树冠」，已作为本地应用 Logo；此前「第二个」被误解为「森林回声」，已纠正。其余候选保留作设计记录。

| 编号 | 文件 | 方向 |
| --- | --- | --- |
| 1 | 01-branch-f.png | 枝芽 F：字母、树枝与星点结合 |
| 2 | 02-forest-echo.png | 森林回声：树冠形成层叠回声 |
| 3 | 03-negative-canopy.png | 负形树冠：实心轮廓中留出树与 F |
| 4 | 04-constellation-grove.png | 星图森林：三棵树与星点连线 |
| 5 | 05-forest-portal.png | 林间之门：双树、小径与星光 |

完整生成提示词和原始文件位置见 `prompts.json`。这些图片为含字标的深色背景概念图；最终选定方案的透明母版和选用记录见 `../../brand/`。应用沿用可访问的文本字标，独立图标使用母版生成。

产品后来更名为 **Formami**。本目录保留生成时的原图、名称和提示词作为创作记录；当前界面使用新名称及已选定的负形树冠图标。
